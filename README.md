## 🎮 About the Game

Microsoft Flight Simulator launched on August 18, 2020, and was developed by Asobo Studio for Xbox Game Studios. It is a civilian flight simulation game featuring detailed aircraft, worldwide scenery, realistic aerodynamics, dynamic weather, live traffic, flight planning, training, activities, and multiplayer flights. The 40th Anniversary Edition released on November 11, 2022, adding helicopters, gliders, historic aircraft, classic airports, and anniversary activities.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Microsoft Flight Simulator (2020) 40th Anniversary Edition**. This trainer provides optional quality-of-life controls for Microsoft Flight Simulator, including flight assistance, aircraft state management, weather and time adjustments, active pause support, and convenient flight-condition toggles. It is intended for offline experimentation, training, sightseeing, and testing aircraft behavior without changing the simulator's aircraft or world content.

**Target Audience:** Suitable for flight-simulation newcomers, experienced simmers practicing procedures, sightseeing players, content creators, aircraft testers, and users who want a more relaxed single-player experience.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Fuel** — Maintains the selected aircraft's fuel reserves during a flight, making long-distance routes and sightseeing flights easier to complete.
- **No Crash Damage** — Prevents crash-related flight termination while experimenting with landings, difficult approaches, aircraft handling, and off-airport operations.
- **Flight Assistance Toggle** — Quickly enables or disables assistance for controls such as throttle, flaps, rudder, taxi guidance, route guidance, and landing guidance.
- **Freeze Aircraft State** — Temporarily stabilizes selected aircraft conditions while the pilot configures instruments, studies the cockpit, or practices procedures.
- **Set Time of Day** — Adjusts the flight time to support daylight, nighttime, sunrise, sunset, and approach practice.
- **Weather Preset Control** — Provides quick access to weather-condition changes for practicing clear-weather, wind, cloud, visibility, and storm scenarios.
- **Active Pause Shortcut** — Provides a convenient shortcut for pausing the simulation while preserving the current flight situation for inspection or planning.
- **Travel To Support** — Helps shorten long flights by making it easier to access the simulator's existing Travel To stages, including climb, cruise, descent, approach, and final.

## 📖 Detailed Feature Guide

### Movement & Exploration

Start a flight from the World Map, choose an aircraft and departure point, then use the trainer only after the aircraft has loaded into the cockpit. Flight assistance can simplify takeoff, taxiing, navigation, and landing. For helicopters and gliders introduced with the 40th Anniversary Edition, use conservative changes and allow the aircraft's flight model to respond naturally. Active Pause is useful for inspecting scenery or preparing the next maneuver without advancing the simulation.

### Tools & Inventory

Microsoft Flight Simulator does not use a conventional inventory system. Aircraft configuration is handled through the aircraft selection, weight and balance, fuel, payload, and cockpit controls available in the simulator. Fuel-related trainer options affect endurance but do not add aircraft, cargo, equipment, or Marketplace content.

### World & Environment

The simulator allows pilots to create routes across the globe using detailed terrain, airports, weather, time-of-day settings, live traffic, and multiplayer options. Weather and time controls are best used before departure or during offline flights. The 40th Anniversary Edition also includes historic aircraft, helicopters, gliders, classic airports, heliports, glider airports, and anniversary activities.

### Combat & Weapons

There is no conventional combat system, weapon inventory, enemy progression, or combat equipment in Microsoft Flight Simulator. The trainer is focused on civilian flight, aircraft handling, navigation, weather practice, sightseeing, training, and activity completion.
